# 设计系统交付记录

当前版本：theme / ui 1.0.0。全部代码在本地，未发布包、未部署网站、未迁移现有系统。

## 验证证据

- pnpm check：生产构建、TypeScript、5 项主题逻辑测试、7 项设计与分发检查测试通过。
- pnpm test:e2e：66 项 Chromium 浏览器测试通过，包含双主题、多宽度、触屏、键盘、减少动态效果、主题同步和演示业务流程。
- pnpm verify:consumer：两个 tarball 在独立应用中安装，类型和生产构建通过；React 实例一致，CSS 不依赖共享源码扫描，主题和移动导航可用。记录见 consumer-verification.json。
- 历史独立 Agent 实验见 agent-verification.md；本轮不进行新的独立 Agent 接入验证或老系统试点。
- 截图及颜色测量见 visual-review.md、screenshots/、contrast.json。

## 实施中的决定

- 原生 worktree 工具不能针对聊天目录下新建的子仓库工作，采用仓库内的 Git worktree；不涉及远程仓库。
- 第一个文档基线提交因 1Password socket 不可达而未签名。用户要求重试后，通过沙箱外 Git 调用成功，后续实现提交使用 1Password 签名。
- 保留已批准的跟随系统 / 浅色 / 深色三种偏好，没有采用外部指南的两状态建议。
- 使用单一根 tsconfig.json，避免增加无实际差异的 base 配置。
- 静态扫描约束常见原始设计值与导入路径；不能识别任意改名复制，仍需人工或 Agent 复核。
- 实际视觉参数为可审核候选，继续完成可逆的模板工作；后续视觉调整可能需要重新生成截图和发布包版本。

## 独立审查与修复

独立审查没有 Critical，发现 3 项 Important，均已补回归并修复：

- 深色危险按钮实际合成色对比度 3.59:1；移除半透明覆盖，组件浏览器对比度测试从失败转为通过。
- 主题菜单 radio item 的触屏高度约 32px；共享规则扩展到 radio、checkbox、sub-trigger，44px 测试通过。
- 独立模板缺少 Agent 规范入口；模板加入 AGENTS.md，UI 包携带版本化规则、参考页面和检查器，外部安装后可读取并运行。

外部安装验证又发现 pnpm 符号链接使检查器未执行 CLI；改为真实路径比较，加入符号链接回归，并在消费副本中故意写入违规颜色，确认检查失败后移除并重新通过。

审查明确未覆盖真实业务 API、SSR Provider、registry 发布、蓄意绕过检查器、跨浏览器/真机验收及用户视觉批准。这些均保持既定范围或待验收状态，不作为已完成事项。没有延期处理的 Minor。

路由分包后的首次加载增加明确的状态反馈，HydrateFallback 警告已由回归测试覆盖。

## 0.2.0 迭代

- 账号设置改为三个水平子页面，支持方向切换，草稿保留，内联保存与全局保存相互独立。跨子页面校验在输入框实际挂载时聚焦错误字段。
- 服务列表采用 64rem 紧凑容器与更小行距。
- 新增仪表盘、图表、用户及客户端管理。后台状态在路由间共享，均为内存演示。
- 用户支持本页全选、跨页选择、确认后批量启用/停用/修改角色；支持 5/10/20/50 条分页与高级组合筛选。
- 批量工具栏压缩为桌面单行：左侧选择人数与清除，右侧操作与应用；触屏仍保留 44px 点击区域。
- 新增 Tabs 与 @cqu-moe/ui/charts 公共入口，Recharts 按图表路由加载。每张图可展开数据表。

本轮独立审查发现两个焦点返回问题：编辑后原行被筛掉、批量操作后筛选结果为空。均已用失败回归复现，再统一回退到仍可用的搜索框，测试通过。
独立消费验证已包含图表子路径、图表渲染和数据表。真实设备与视觉最终确认的边界不变。

## 登录注册示例

新增 /auth 二合一入口、独立无侧栏布局、邮箱/密码与注册显示名称、密码可见切换、校验与提交状态。切换模式清空密码，定时器在卸载时取消；不发送凭据，不写入存储，不创建真实会话。注册密码最少 8 个字符仅为示例规则。桌面/手机与双主题均有截图和交互测试。

## 0.3.0 通知与反馈

新增 /feedback 页面与共享 Sonner Toaster、toast、Alert。应用与启动模板只挂载一个通知容器，跟随现有主题；设置保存、用户批量操作和客户端操作的成功结果接入 Toast，字段错误仍在原位，避免双重反馈。

示例覆盖同 id 更新、异步成功/失败、撤销、手动关闭、持续通知条、行内校验、弹窗与侧栏动效。系统减少动态效果与页面预览均受支持，键盘通知即时出现。Sonner 原生堆叠与滑动机制保留，没有自建通知队列或后端消息中心。

通知依赖接入后主入口约 520 kB（gzip 161 kB），构建有 500 kB 阈值提示；没有提高阈值掩盖提示。真实设备仍待验收。

## 0.4.0 按钮结果与彩色通知

新增受控 ActionButton，展示操作、进行中、成功、失败重试；采用预留宽度的同格文案/图标过渡。进行中阻止重复点击并保留焦点，业务拥有真实请求状态；示例计时器在页面卸载时清理。

/feedback 展示仅按钮反馈、失败的行内解释、按钮结果加可操作 Toast。Toast 改为淡色语义背景与彩色标题/图标，普通 4 秒、较长或可操作提示 8 秒后自动收起，保留页面内恢复入口。系统或预览减少动态效果时取消按钮位移与旋转。

53 项浏览器测试通过。新增对成功/失败按钮和四类 Toast 的实际合成色对比度检查，浅深两种主题均达到 4.5:1；自动消失、重试、固定宽度与防重复行为有回归。
