# 设置交互与后台示例迭代

用户已指定本次修改，沿用已批准的技术栈与设计系统。

1. 设置改为个人资料、外观、通知三个横向子页面。草稿不因切换丢失；向后一个选项切换时内容向左推进，返回反向；键盘及减少动态效果模式即时切换。
2. 显示名称、邮箱支持独立保存；底部全局保存提交全部草稿。独立保存只验证和更新当前字段，其他草稿仍保持未保存；失败保留输入，提交期间防止竞态。
3. 服务列表桌面最大内容宽度收至 64rem，缩小行距；手机仍保留完整操作与详情入口。
4. 新增本地后台示例：仪表盘、分析图表、用户管理、客户端管理。管理页面提供搜索、筛选、详情和示例编辑，均明确为演示数据。
5. 图表使用 Recharts，统一样式与可访问的数据表替代视图；时间趋势用折线/面积，分类比较用条形。共享包新增 Tabs 和图表组件。

验证覆盖：子页面选择/键盘/方向/减少动态效果；独立和全局保存的状态隔离/失败；桌面密度；后台页面搜索和演示操作；双主题、多宽度、真实打包安装。视觉仍以用户最终审核为准。
