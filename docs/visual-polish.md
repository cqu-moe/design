# 1.1 视觉调整

以用户提供的 Vercel 仪表盘截图为视觉方向：中性画布、白色内容卡片、细边界、贴近表面的轻投影，依靠标题、间距与对齐形成层次。

## 最终配色与表面

- 所有页面背景恢复中性白色／石墨灰；无品牌色大背景、绿色光晕或渐变。
- 浅色 primary 从 oklch(.25 0 0) 改为 oklch(.22 0 0)，深色从 oklch(.9 0 0) 改为 oklch(.93 0 0)，用于紧凑主按钮。
- 浅色 border 从 oklch(.895 0 0) 改为 oklch(0 0 0 / .1)，以透明细边界区分白色内容面。
- 新增 shadow-card：浅色为 0 1px 2px black/4% + 0 2px 4px black/2%，深色为 0 1px 2px black/12%；边界仍由 border 承担。
- 输入与次要按钮使用 card，移除深色模式中的 input/30 灰色整块填充。保留中性焦点与可见输入边界。
- Auth 设置标题放到内容卡片外，表单展开使用中性底色。取消彩色标题线、卡片顶边与选中导航侧边条。

## 动效

按钮指针按压 150ms、scale(.97)；键盘即时。开关滑块 180ms，从当前位置继续。Auth 行内编辑器仅在指针展开时做 4px、180ms 的进入反馈；不支持 starting-style 的浏览器直接显示。减少动态效果取消位移与缩放。

模板和接入提示词明确上述视觉规则，要求实际查看双主题、桌面与手机截图。

## Vercel 原文对应

来源：[vercel.com/design.md](https://vercel.com/design.md)，2026-09-29 阅读。该文件面向报告网站；本次取其排版、分组与克制原则，应用到现有产品组件，不替换 CQU 身份、路由和主题能力。

- 先明确当前页的主要任务，再安排层次。Auth 账户页只保留一处用途说明，去掉重复描述与额外装饰指纹。
- 同组内容共享对齐、数字位置和间距。仪表盘四个同类指标合成一组，内部用分隔线，避免四张相同卡片争抢注意力。
- 先用字号、字重与分组间距组织内容，再决定边界；设置页区块标题在内容面外，普通卡片不反色。
- 大面积保持中性；链接和真实状态才使用颜色。保留一个明确主动作，不用色条、渐变或图标底块替代层次。
- 动效仅反馈操作与状态，基础内容始终可读；键盘与减少动态效果保持即时。

验收同时看第一屏和整页、明暗主题与窄屏：遮住具体文案后仍能辨认主次和分组；每个多余框、重复说明与装饰图标都应有保留理由。
