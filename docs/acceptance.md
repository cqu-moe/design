# 子系统交付检查

先执行项目自身的类型、单元和集成检查，再执行以下设计接入检查；命令成功后仍需查看页面。

## 必须运行

```sh
pnpm build
pnpm check:design
```

使用项目已有浏览器测试工具检查下面的流程；模板不另装第二套测试框架。检查器只验证常见设计值/导入问题，不保证视觉一致，也不能发现所有复制或权限错误。

## 页面检查矩阵

| 项目 | 验收内容 |
| --- | --- |
| 主题 | 浅色/深色/跟随系统；刷新无明显错色、偏好保留；无纯黑背景 |
| 布局 | 390、768、1440px × 双主题，320px 防溢出；长中文/英文标识不截掉核心内容 |
| 手机 | 所有操作可达，输入至少16px，触屏控件至少44px，表格只在内部横向滚动 |
| 状态 | 初始加载、刷新、真空数据、筛选为空、网络失败、403、404、只读/禁用 |
| 表单 | 标签关联、错误后可修正、草稿保留、Enter提交、加载防重、失败重试、成功后编辑重置 |
| 浮层 | Escape关闭、焦点限制及返回、触发项消失后的回退、不残留遮罩/滚动锁 |
| 图标 | lucide-react、约定尺寸/描边/间距、图标按钮有动作和对象名称、装饰不重复朗读 |
| 通知 | 全局唯一Toaster、语义色和文字、4秒默认自动消失、必要恢复入口仍留在页面 |
| 动效 | pointer/keyboard/减少动态效果；按钮宽度不跳动；查询、分页和图表不强加入场 |
| 图表 | 可展开数据表、单位/标签完整、颜色不成为唯一编码 |
| 真实接口 | 成功/失败合同匹配、过时响应不覆盖、权限由后端执行、写入结果授权环境读回 |


不要把 Chromium 触屏模拟称为真机测试，不把编译成功称为完整业务验收。未做的检查明确列出，不能记为通过。
