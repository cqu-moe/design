# 动效

执行用户指定的 animate 技能；先判断频率和目的，再决定效果。

| 场景 | 时间与效果 |
| --- | --- |
| 页面导航、键盘输入、选项高亮 | 即时，无入场动画 |
| 按钮反馈 | 150ms；仅指针按压 scale(0.97)，键盘即时 |
| 开关滑块 | 180ms ease-out，改变方向时从当前状态继续 |
| 弹窗、菜单、选择器 | 入场 180ms、离场 140ms；0.98 缩放与透明度 |
| 手机导航 | 入场 220ms、离场 160ms；从导航所在侧进入 |
| 主题切换 | 即时，无整页颜色过渡 |

位移和缩放使用 cubic-bezier(0.19, 1, 0.22, 1)。默认无弹跳。
键盘触发和 prefers-reduced-motion 时浮层即时显示，保留完整功能和焦点反馈。
浮层生命周期由 Radix 管理；退出后须验证遮罩、滚动锁和焦点均恢复。
不对列表逐项入场，不嵌套多层入场，不使用 transition: all。
来源：animate/SKILL.md 与 css-techniques.md。与其他技能的 ease-in 离场建议冲突时采用 animate。

账号设置子页面按用户要求支持方向切换：前往右侧选项时新内容从右向左进入，返回反向，位移 16px、180ms。不叠加整页转场；键盘和减少动态效果模式保持即时切换，草稿不随内容卸载丢失。

Toast 使用 Sonner 原生堆叠、退出与滑动关闭动效，不再叠加额外入场。尊重系统减少动态效果；通知页可临时预览减少动效，离开后恢复。

ActionButton 文案使用同格交叉淡入与 4px 位移，150–180ms；按钮宽度不变。状态颜色以 180ms 过渡，加载指示 900ms 旋转。键盘取消文案位移，系统或预览减少动态效果时取消位移与旋转。


## 示例页覆盖

| 页面 | 动效与反馈 |
| --- | --- |
| 账号设置 | 子页面方向切换；内联与全局保存复用 ActionButton，编辑后重置状态 |
| 登录 / 注册 | 模式切换淡入；提交按钮显示进行中、成功、失败，加载时保留按钮焦点 |
| 服务列表 / 详情 | 复用按钮按压、菜单动效；搜索、筛选、分页与导航即时响应 |
| 用户管理 | 编辑与确认弹窗、筛选抽屉复用共享动效；批量选择即时，完成后 Toast |
| 客户端管理 | 新建弹窗、详情侧栏与操作 Toast 复用共享动效 |
| 仪表盘 / 数据分析 | 日期和数据切换即时；不对数字、图表和表格增加重复入场 |

状态变化复用共享组件，不为每个页面另建动效。表单加载时拦截重复提交，离开页面取消演示定时器；失败保留输入以便重试。
